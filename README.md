# TOTU — audyt i kierunek rozwoju strony

Statyczna, responsywna prezentacja audytu `totunieruchomosci.pl` przygotowana na podstawie
publicznej wersji witryny z 11 sierpnia 2026 r.

## Podgląd lokalny

Uruchom w tym katalogu:

```powershell
python -m http.server 4173
```

Następnie otwórz `http://127.0.0.1:4173/`.

Projekt nie wymaga instalowania zależności ani procesu budowania.
